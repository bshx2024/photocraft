Frequently Asked Questions About PhotoCraft Photoshop Alternative

Answers to common questions regarding PhotoCraft features, PSD file support, and browser performance.

What is PhotoCraft?

PhotoCraft is a clean-room Photoshop alternative developed in pure Rust by the ArtCraft project. It delivers 1:1 workflow parity with Adobe Photoshop, including multi-layer PSD editing, layer styles, masks, adjustment layers, and GPU-accelerated compositing without subscription fees.

Is PhotoCraft a free open-source Photoshop clone?

Yes. PhotoCraft serves as a clean-room open-source Photoshop clone engineered in pure Rust. It maintains 1:1 parity with Photoshop's toolbars, layer blend modes, and shortcuts (such as Cmd/Ctrl+J and Cmd/Ctrl+T) so creative professionals can open and edit layered PSD files without retraining.

Where can I find PhotoCraft discussions on Reddit and GitHub?

The PhotoCraft community and user benchmarks are actively discussed on Reddit (including r/opensource and r/rust) and on the official storytold/photocraft GitHub repository where full source code and release builds are distributed.

How does PhotoCraft compare to Adobe Photoshop?

PhotoCraft replicates Photoshop's exact menus, panels, and shortcuts (such as Cmd/Ctrl+J for layer duplicate and Cmd/Ctrl+T for free transform). Unlike Adobe Photoshop, PhotoCraft is completely free, requires no monthly subscription, runs offline, and supports automated AI workflows.

Can PhotoCraft open and edit Photoshop PSD files?

Yes. PhotoCraft features a custom-built PSD and PSB format engine that preserves complex layer hierarchies, blend modes, vector masks, and layer effects like drop shadows and strokes without flattening.

Is PhotoCraft completely free to use?

Yes, PhotoCraft is 100% free and open source under permissive licenses. There are no subscriptions, ads, account paywalls, watermarks, or artificial feature limitations.

Does PhotoCraft run in modern web browsers?

Yes. The exact same Rust engine compiles to WebAssembly with WebGPU and WebGL2 acceleration, letting users open, edit, and export PSD and image files directly inside any modern web browser without installing additional software.

How does PhotoCraft differ from GIMP as a Photoshop alternative?

While GIMP uses a custom interface and non-standard keyboard shortcuts, PhotoCraft strictly follows Photoshop's user interface and shortcut standards, allowing Photoshop users to switch immediately with zero retraining.

Where can I download the native desktop version of PhotoCraft?

Native standalone desktop binaries for Windows, macOS, Linux, and FreeBSD are available on the official GitHub repository releases page without web wrappers or Electron bloat.

Does PhotoCraft support graphics drawing tablets and stylus pens?

Yes. PhotoCraft includes native pen tablet input support across Windows, macOS, and Linux, handling pressure sensitivity, tilt, and rotation dynamics seamlessly for digital painting.

What image file formats can PhotoCraft import and export?

Beyond Adobe Photoshop PSD and PSB files, PhotoCraft supports layered TIFF, Paint.NET PDN, vector SVG, and raster formats including PNG, JPEG, WebP, GIF, BMP, OpenEXR, and HDR.
